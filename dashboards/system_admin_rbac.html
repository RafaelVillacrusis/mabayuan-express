System Admin Highest Access

Full platform control.

  • ✓ Manage all user accounts
  • ✓ Configure document types
  • ✓ Full audit trail access
  • ✓ Export system backup
  • ✓ RBAC control panel
Captain Elevated Access

Approves requests, manages the office.

  • ✓ Approve/reject requests
  • ✓ Configure document types

🛡️ Security & Access Policy

  • Every API endpoint is protected by requireRole() middleware — unauthorized access returns 403 Forbidden.
  • Session-based authentication: roles are validated on every request against the active session.
  • A System Admin cannot remove their own admin role or delete their own account.
  • All role changes are written to the Audit Trail with actor, timestamp, and old/new role.
  • Residents authenticate via a separate portal and can never access personnel dashboards.
